# 台中無界｜TAICHUNG: UNBOUND

A cross-era open-world adventure inspired by Taichung, Taiwan.

## 🎮 Project Concept

《台中無界》是一款以台灣台中為核心的跨年代開放世界遊戲。

玩家可以選擇不同年代與區域，體驗每個時期不同的：

- 城市風貌
- 鄉村與海線
- 車輛與機車
- 美食與市場
- 夜市與漁港
- 角色造型
- 寵物系統
- 多人組隊任務
- 城市生活任務
- 犯罪與追逐玩法

## 🕰 Era Worlds

- 1950–60s｜CITY OF TIME｜時城
- 1970s｜STREET ERA｜街代
- 1980s｜NEON YEARS｜霓虹年代
- 1990s｜STREETLINE｜街線
- 2000s｜NO LIMITS｜無限界
- Modern｜OUTLAW CITY｜狂城
- REWIND｜倒帶｜跨年代主線
