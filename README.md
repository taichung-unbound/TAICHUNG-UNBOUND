# 幻都異世界｜PHANTOM METROPOLIS

**A cross-era open-world adventure in a fictional metropolis inspired by Taiwanese city life.**

《幻都異世界》是一款具有台灣城市生活氛圍的跨年代 3D 開放世界遊戲企劃作品。

玩家能在不同年代、台中各區域所啟發的遊戲地圖之間探索、生活、工作、組隊、執行任務、購置房屋與車輛、飼養寵物，並體驗城市的文化、美食與日常故事。

> **世界觀原則**：遊戲以台中真實區域作為地圖規劃與城市特色的參考，保留市中心、海線、山線、屯區等原有範圍，不刪除真實區域原型。正式遊戲可將地區與地標改用虛構名稱，店家、百貨、品牌、招牌及 Logo 使用虛構設計；道路、建築及地標不做 1:1 還原，配置可依玩法調整。真實參考區域與遊戲內虛構名稱應保留對照。不製作可辨識的軍營、軍事基地、雷達站等敏感設施。

## 🎮 Core Concept｜遊戲核心

**台中區域原型 × 虛構城市名稱與地標 × 跨年代 × 開放世界 × 多人合作 × 城市生活 × 多元任務**

主要規劃特色：

- 高品質寫實 3D 城市與可探索場景
- 六個年代及跨年代劇情模式
- 完整自訂角色與捏角系統
- 貓狗寵物夥伴
- 不同年代的汽車、機車及交通工具
- 房屋、資產與室內生活
- 生活經濟、外送與工作
- 主線、支線、探索與犯罪題材任務
- 多人合作與組隊
- 台中各區域啟發的生活、飲食與在地文化氛圍
- 配音、音樂及環境聲

## 👤 Character System｜主角與捏角

玩家可自行建立與保存角色，不能以一般 NPC 的固定外型取代主角捏角。

規劃包含：

- 男性、女性角色及多種外觀選擇
- 臉型、眼睛、鼻子、嘴巴、下巴、膚色等臉部細節
- 髮型、髮色、身高、肩寬及整體比例
- 男性肌肉、腹肌等體態細節（包含八塊腹肌方向）
- 女性腿長、腰線與胸腰臀等體型比例調整
- 服裝、鞋子、背包、配件與不同年代的造型
- 角色資料與外觀設定保存

**美術方向**：自然人物比例、細緻材質及高品質寫實 3D。主角必須能隨玩家選擇而調整；城市 NPC 則可以使用寫實風格的固定角色資產。

## 🏠 Housing & Property｜住宅與資產

玩家由初始雅房或簡易套房起步，隨遊戲進展升級居住空間：

初始雅房／套房 → 標準套房 → 公寓 → 透天 → 高級住宅 → 別墅 → 豪宅／莊園

可規劃購買家具、車庫、寵物設備、室內裝潢及收藏展示。未來可讓玩家實際進入部分建築與室內空間。

## 🚗 Vehicle System｜載具系統

依年代提供汽車、機車、速克達、腳踏車、貨車、外送車及其他適合的交通工具。

規劃支援上下車、駕駛、購買、改裝、維修、加油、車庫管理，以及與任務連動的搶車、追捕等玩法。車輛與騎士的比例、動作和視覺品質須符合寫實方向。

## 💰 Economy & Life｜經濟與生活

玩家可透過外送、計程車、物流、市場及商店工作、地方產業工作、一般任務、多人合作及高風險任務取得遊戲貨幣。

可用於食物、服飾、汽車、機車、房屋、家具、寵物用品、維修、加油及娛樂等。

> 舊企劃使用「TC 幣」作為貨幣名稱。因世界觀已改為《幻都異世界》，此名稱暫列為**待確認**，不在本次 README 修改時自行決定新名稱。

## 🚨 Mission & Crime｜任務系統

任務包含主線、支線、生活任務、地區任務、年代任務、多人任務與隨機事件。

犯罪題材玩法的原始規劃包含搶車、搶劫、黑市委託、幫派任務、地下競速、警察追捕及通緝機制；具體設計、分級和實作範圍待後續確認。

## 💾 Save & Sync｜存檔與同步

長期方向為使用伺服器儲存玩家角色、貨幣、房屋、車輛、寵物、任務、收藏、年代與地區進度，讓玩家跨裝置繼續遊戲。

## 🖼 Visual Direction｜美術與展示版本

- **美術基準**：具台灣城市生活感的高品質 AI 寫實街景參考圖；虛構建築、店招和路標。
- **圖片式 HTML 展示**：可用 AI 參考圖呈現高品質畫面，但不等於可自由走動的完整 3D 世界。
- **正式 3D 遊戲**：應使用可實際操作的場景、角色、載具、模型與材質資產，不以平面背景冒充可探索城市。
- **版本驗收**：未經確認的獨立 HTML 預覽，不視為正式遊戲功能或核准版本。

## 🎯 Vision｜遊戲願景

《幻都異世界》希望讓玩家在具有台灣城市氛圍的虛構世界裡，自由選擇年代與地區、建立專屬角色、與寵物共同生活，並透過探索、工作、任務、交通、購物、住宅與多人互動，體驗屬於自己的開放世界故事。
