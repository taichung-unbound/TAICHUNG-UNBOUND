# 幻都異世界｜PHANTOM METROPOLIS｜Account & Login System

## 01｜登入方式

第一版正式帳號系統規劃支援：

- Google 登入
- Email 驗證碼登入

之後可擴充：

- Apple 登入
- Discord 登入

**開發狀態說明：**以上是正式版本的規劃需求，不代表目前遊戲 Prototype 已完成第三方登入、Email 驗證或正式後端帳號系統。現有的展示登入與訪客入口應和正式帳號驗證區分。

---

## 02｜帳號原則

原始原則：**一個 Email 對應一個《幻都異世界》遊戲帳號。**

帳號與角色分開管理。

建議：

- 每個帳號可建立 1～3 個角色（確切上限待正式確認）
- 不需要為不同角色重新註冊帳號
- 男／女角色可自由建立
- 不同角色可擁有不同外觀、服裝、寵物與進度

**帳號綁定補充：**Google 與 Email 驗證碼若使用相同電子郵件，應由正式帳號系統確認登入身分及綁定關係，避免誤建立重複帳號；不得僅憑未驗證的 Email 文字自動合併帳號。具體驗證、綁定與解除綁定方式留待技術設計確認。

---

## 03｜Email 驗證

Email 註冊／登入時：

1. 玩家輸入 Email
2. 系統寄送一次性驗證碼
3. 玩家輸入驗證碼
4. 驗證成功後建立或登入帳號

驗證碼需具備：

- 有效時間限制
- 使用一次後失效
- 錯誤次數限制
- 重寄冷卻時間

**原則：**驗證碼有效期限、重寄次數、錯誤次數與寄送服務等細節，待正式開發時確認；本文件不視為相關機制已實作。

---

## 04｜防止大量濫用註冊

第一版規劃：

- Email 驗證
- CAPTCHA
- IP 註冊頻率限制
- 裝置識別
- 短時間大量註冊偵測
- 可疑帳號標記
- 封鎖異常帳號

不採用：

- 身分證驗證
- 高敏感個資驗證

**隱私與安全原則：**裝置識別及異常行為偵測應採必要且適度的方式設計，並提供合理的隱私告知；不因防濫用需求而擅自收集高敏感個資。

---

## 05｜角色建立

登入成功後：

若帳號沒有角色：

→ 建立角色
→ 完整捏角
→ 選擇初始寵物
→ 儲存角色與初始寵物設定

若已有角色：

→ 選擇角色
→ 讀取該角色與既有進度

每個角色可保存：

- 角色名稱
- 性別／體型
- 臉型
- 膚色
- 髮型
- 髮色
- 身高
- 身材
- 上衣
- 下身
- 鞋子
- 配件
- 背包
- 寵物
- 當前年代
- 當前區域
- 遊戲進度
- 金錢
- 任務紀錄
- 收藏紀錄

**資料關聯原則：**帳號用來管理登入與角色清單；每位角色的捏角、寵物、資產和進度應各自保存，不會因登入或切換角色而被另一角色覆蓋。更完整的房屋、車輛、NPC 關係、同步與存檔細節，須與 `CHARACTER-CUSTOMIZATION-SYSTEM.md`、`PET-COMPANION-SYSTEM.md` 及 `SAVE-SYNC-SYSTEM.md` 對齊。

## 06｜正式進入遊戲流程

### 首次登入／尚無角色

登入或建立帳號
→ 建立第一個角色
→ 完整捏角
→ 選擇初始寵物
→ 建立角色初始資料
→ 取得新手小套房與基本生活資金
→ 選擇年代
→ 選擇地區
→ 選擇遊戲模式
→ 載入角色造型、寵物、車輛與玩家資產
→ 進入世界／新手教學

### 再次登入／已有角色

登入
→ 顯示既有角色清單
→ 選擇角色
→ 讀取角色與寵物等既有資料
→ 選擇年代
→ 選擇地區
→ 選擇遊戲模式
→ 載入該角色造型、寵物、車輛與玩家資產
→ 進入世界

**重要：**不要求玩家每次登入都重新捏角、重選初始寵物，或重新取得新手資產；已保存的內容應依角色進度恢復。年代、地區及遊戲模式的選擇與解鎖條件以 `GAME-FLOW.md` 為整體規劃基準。

**地圖與世界觀：**遊戲包含原本規劃的台中市中心、海線、山線、屯區等完整區域原型；正式遊戲可使用虛構地區名稱及地標，但不刪除原始探索範圍。

**狀態區分：**本章描述正式遊戲目標流程；目前 Prototype 的展示登入和基本 3D 互動，不代表以上帳號服務、存檔與跨裝置同步已完成。

## 07｜帳號安全

後續正式版本應加入：

- Session / Token 管理
- 登出所有裝置
- 登入紀錄
- 異常登入提醒
