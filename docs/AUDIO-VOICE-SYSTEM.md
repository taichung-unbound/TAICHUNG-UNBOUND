# 幻都異世界｜PHANTOM METROPOLIS｜Audio & Voice System

## 01｜核心目標

《幻都異世界》的聲音必須和畫面一樣具備真實感。

目標：

**讓玩家不只看得出具有台灣城市氛圍的世界，也能聽得出台灣的日常生活與不同年代。**

**世界觀原則：**以台中市中心、海線、山線、屯區等地區的環境及文化特色為設計原型，保留原先完整的探索範圍與生活場景。正式遊戲使用虛構地名、商店及地標，不要求真實地點 1:1 還原；地圖範圍依 `MAP-TAICHUNG-SYSTEM.md` 為準。

**版本定位：**本文件是聲音設計與後續實作驗收的企劃規格，不表示正式配音、動態混音或 3D 空間音效已實作完成。

---

## 02｜角色配音

支援：

- 國語
- 台語
- 族語
- 英語
- 其他外語

角色包含：

- 主線角色
- 隊友
- NPC
- 警察
- 店家
- 市場攤販
- 外送員
- 路人
- 幫派角色
- 酒吧／KTV 人物

**角色連動：**玩家創角時選擇的聲線，需與 `CHARACTER-CUSTOMIZATION-SYSTEM.md` 及 `SAVE-SYNC-SYSTEM.md` 對齊；重新登入後應還原既有聲線設定。NPC 配音需依人物身份、年代、語言及劇情情境調整，不應讓所有人物使用相同聲音。

**實作原則：**配音語言、角色聲線、環境人聲及玩家多人語音是不同功能，需分別規劃與測試；可先以合法素材做原型驗證，不代表正式配音已製作完成。

## 03｜字幕系統

可切換：

- 繁體中文
- English

後續可擴充：

- 日本語
- 한국어

配音與字幕可分開設定。

**操作原則：**玩家應可分別選擇配音語言及字幕語言。任務對話、NPC 互動和重要情節應保持字幕與實際播放內容同步；字幕顯示大小、對比及背景可讀性可納入無障礙與介面規劃。

**存檔原則：**字幕、配音語言及音量等偏好可依既定設定資料保存；角色專屬聲線則依角色資料保存，不可混為同一欄位。

## 04｜台灣語言與文化

角色語言依：

- 地區
- 年代
- 家庭背景
- 角色個性
- 劇情情境

自由配置。

原住民族角色：

- 不使用單一刻板形象
- 不把族群設定成固定能力
- 不預設所有角色都喝酒或唱歌
- 每個角色擁有自己的工作、個性與生活方式

可加入：

- 族語對話
- 音樂
- 地方故事
- 家庭故事
- 現代都市生活
- 部落與山區生活

**文化原則：**不同族語、台語用字及地方語音的使用，應在製作時尊重實際語言與文化脈絡；需要時邀請熟悉相關語言與文化者協助校對。角色個性、職業、能力與行為不能由族群身份直接決定。

**素材原則：**真實歌曲、KTV 伴唱音樂、現場演出錄音與商用背景音樂，應先確認合法使用與公開發行所需的授權，不直接把未授權歌曲納入正式遊戲。

## 07｜酒精系統

玩家可在遊戲內飲酒。

可能效果：

- 畫面輕微晃動
- 操作反應下降
- 對話選項改變
- 行走狀態改變
- 特殊社交事件

安全設計：

飲酒後駕駛可觸發：

- 警察攔查
- 罰款
- 通緝／案件
- 交通事故風險
- 任務失敗

**系統連動：**飲酒狀態應與角色操作、載具駕駛、警察反應及 `MISSION-CRIME-SYSTEM.md` 的任務結果保持一致；本章描述遊戲機制，不代表已完成功能或鼓勵現實危險行為。

## 10｜音樂系統

不同年代有自己的音樂方向。

音樂會依：

- 年代
- 地區
- 時間
- 天氣
- 任務
- 犯罪狀態
- 警察追逐
- 酒吧／KTV
- 劇情

動態切換。

**動態原則：**背景音樂與現場音源應區分。劇情、任務與追捕音樂的切換需避免突兀中斷；市場、店內音樂與街道環境聲不可無限制疊加，以維持人物對話可聽性。

**授權原則：**正式公開版本需使用原創、已取得授權或符合使用條件的音樂與聲音素材；素材來源、授權範圍及使用限制應可追溯。若使用生成式音訊，也需確認其適用條款與必要的人聲、音樂權利。

## 11｜多人語音

後續多人模式規劃：

- 隊伍語音
- 距離語音
- 靜音
- 單獨關閉玩家聲音
- 檢舉
- 語音權限設定

第一版 Prototype 可先不實作。

**多人原則：**隊伍語音與依玩家位置衰減的距離語音需分開處理；玩家應能控制是否啟用麥克風、單獨靜音及檢舉。麥克風授權、玩家隱私及語音濫用防護須在多人功能開發時一併規劃。

**版本原則：**尚未實作語音傳輸、距離混音與權限控制前，不可將示意按鈕或假語音動畫視為多人語音已完成。

## 12｜核心原則

《幻都異世界》的聲音不是背景裝飾。

它必須成為：

**城市、年代、人物與生活感的一部分。**

聲音設計需要和角色、地區、天氣、載具、任務、犯罪狀態及玩家選擇互相呼應，讓玩家能在具有台灣文化與生活特色的虛構城市裡，真實感受不同年代的日常。

**完成判定：**AI 音訊參考、單獨播放的音效、影片或圖片式 HTML 預覽，只能作為設計展示；正式完成需在可操作的 3D 遊戲場景中驗證聲音方向、距離、遮蔽、室內外切換、年代差異、字幕同步、音量設定及素材合法性。未經使用者確認，不得擅自覆蓋 GitHub 正式遊戲程式。
