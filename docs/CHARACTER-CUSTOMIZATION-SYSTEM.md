# 幻都異世界｜PHANTOM METROPOLIS｜Character Customization System

## 01｜核心概念

《幻都異世界》採用完整角色自訂系統。

玩家不是固定使用同一位主角，而是可以建立自己的角色。玩家建立的主角與城市 NPC 必須區分，不以固定的 NPC 外觀或簡化人形取代完整主角捏角。

官方角色可作為：

- 宣傳主角
- 預設角色
- 劇情角色
- 捏角模板

**角色定位：**

- **玩家主角：**由玩家建立與保存，能調整臉型、身材、髮型、服裝及配件等完整設定。
- **城市 NPC：**路人、店員、外送員、機車騎士、任務人物等，可使用符合城市與年代的寫實固定角色模型；不因此限制玩家主角的捏角自由。
- **AI 視覺參考角色：**用於確認風格和形象，不代表已完成可操作的 3D 模型或捏角功能。

---

## 02｜角色建立流程

建立角色
→ 選擇體型
→ 調整臉部
→ 調整身材
→ 選擇髮型
→ 選擇髮色
→ 選擇服裝
→ 選擇配件
→ 儲存角色

以上為角色建立的核心步驟；與年代、地區、寵物及遊戲模式的完整進入順序，仍以遊戲流程文件整合確認，不在本文件擅自變更。

## 15｜視覺品質

角色必須符合：

- 高擬真 3D
- 電影感光影
- 真實皮膚質感
- 真實布料
- 真實頭髮
- 自然身體比例
- 高品質臉部表情

避免：

- Q 版
- 卡通化
- 過度動漫化
- 塑膠感人物

### 主角與 NPC 的美術區分

- **主角：**需使用可支援捏角、換裝、動作和外觀保存的高品質 3D 角色資產；不能把 AI 參考圖或固定 NPC 模型當成已完成的捏角系統。
- **NPC：**可使用你認可的 AI 寫實街景圖片作為美術標準，包括路人、外送員、店員及騎士；正式遊戲仍需對應可放入場景、可配合動作的 3D 資產。
- **圖片式 HTML 視覺展示：**用來驗證畫面風格與介面，不等於具備可自由走動、可轉視角、可捏角的完整 3D 互動。
- **完成判定：**必須檢查瀏覽器實際渲染和操作表現；未經使用者確認的展示版本不得直接取代正式遊戲版本。

---

## 16｜核心原則

玩家的角色必須是：

**自己的角色、自己的年代造型、自己的生活方式。**

《幻都異世界》的主角自訂規劃必須完整保留，不因製作街景、NPC 或視覺預覽而簡化原有臉部、身材、服裝、年代與角色保存需求。
