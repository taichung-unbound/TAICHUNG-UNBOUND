# 幻都異世界｜PHANTOM METROPOLIS｜Economy & Life System
## 經濟、工作與日常生活系統

**版本定位：**本文件依已確認的遊戲方向及相關系統需求重新整理，作為經濟與生活企劃及後續驗收依據，不代表已找回原始經濟文件，也不表示以下功能已實作。原有住宅需求保留於 `HOUSING-PROPERTY-SYSTEM.md`。

**世界觀原則：**以台灣／台中市中心、海線、山線、屯區等地區的地理、文化及生活特色為設計原型，保留完整探索範圍。正式遊戲使用虛構地名、商店、品牌、勢力及地標，不要求真實地點 1:1 還原；地圖範圍依 `MAP-TAICHUNG-SYSTEM.md`。

## 01｜核心目標

《幻都異世界》的經濟與生活系統，讓玩家透過工作、探索、任務及自己的選擇，逐步在城市中建立生活。

核心循環：

探索 → 工作與任務 → 取得收入 → 日常消費 → 累積資產 → 改善生活 → 解鎖更多玩法

保留：

- 生活工作與外送。
- 主線、支線、地方故事及多人合作。
- 犯罪與高風險任務。
- 買衣服、買菜、買食物與叫外送。
- 買車、騎車與駕駛。
- 養寵物與寵物照護。
- 租屋、買房、裝潢與住宅成長。
- 六個年代與 REWIND。

玩家可選擇不同生活路線，生活工作與犯罪任務均為既定玩法，不把某一條路線訂為所有玩家必須採用的成長方式。

## 02｜正式貨幣：VE 幣

正式遊戲貨幣為：

**VE 幣｜介面縮寫 VE**

工作報酬、任務收入、購物、住宅、載具、寵物及其他既定金錢結算，統一以 VE 幣表示。

**顯示原則：**餘額、單價、數量、總價與交易結果需清楚區分；同一筆交易在商店、任務、背包與存檔中的金額應一致。

**待確認項目：**初始金額、價格、報酬、金額精度、持有上限及平衡數值需另行確認。本文件不設定 VE 與現實貨幣的匯率，也不據此新增儲值、兌現或付費制度。

## 03｜新角色的基本生活

依 `GAME-FLOW.md`、`ACCOUNT-LOGIN-SYSTEM.md` 及住宅文件，首次建立角色需銜接：

- 建立角色與完整捏角。
- 選擇初始寵物。
- 建立初始角色與寵物資料。
- 取得免費臨時借住使用資格與基本生活資金，不直接贈送永久房產。
- 依既定流程選擇年代、區域與模式。
- 進入世界及新手教學。

**資料原則：**臨時借住使用資格、初始寵物及基本生活資金只依首次建立規則提供；重登、重試或更換裝置不得重複發放。既有借住、租屋或購屋狀態需正確還原。具體資金與初始物品清單待確認。

**住宅起步：**新角色與初始寵物先在免費臨時借住空間落腳，不設定倒數搬離期限。玩家可透過「在幻都安頓下來」任務賺取 VE 幣，租用雅房／簡陋套房，再累積收入購買住宅。臨時借住使用資格、租用權及購屋所有權需明確區分；詳細規則與七階段住宅成長依 `HOUSING-PROPERTY-SYSTEM.md`。

## 04｜收入來源

既定收入方向包含：

- 主線任務。
- 支線任務。
- 生活工作。
- 外送。
- 多人合作任務。
- 高風險任務與犯罪玩法。

**結算原則：**需明確記錄完成條件、成功／失敗、報酬與相關成本。接取任務或進入工作場景，不等於已取得收入；發放時機依確認後的任務規則處理。

任務可能提供經驗、車輛、衣服、寵物、房屋、收藏品或聲望等非貨幣結果，依 `GAME-FLOW.md` 及 `MISSION-CRIME-SYSTEM.md`，不將所有獎勵改成 VE。

各工作的種類、門檻、報酬、時限及重複接取規則待後續確認。

## 05｜生活工作

玩家可透過城市與地方生活工作取得收入，保留日常工作路線。

工作流程需求：

查看工作 → 確認條件與報酬 → 接取 → 前往場所 → 實際執行 → 判定結果 → 結算與保存

工作內容應配合區域、年代、營業時間及情境。市中心、海線、山線、屯區、鄉村與漁港可以具有不同工作方向，具體職業清單需另行確認，不以未確認的示例取代既定工作企劃。

**操作要求：**正式工作需有實際目標、互動與結果。不能只點擊按鈕增加金額，就宣稱完整工作玩法完成。

## 06｜外送工作與叫外送

### 玩家從事外送

流程需求：

接單 → 查看店家與目的地 → 前往取貨 → 確認貨物 → 配送 → 完成交付 → 結算收入

需與角色、地圖、載具及任務系統連動。取貨、配送及交付狀態須可辨識，並區分進行中、成功、失敗與取消；時限、貨物狀況、費用及取消後果待確認。

### 玩家訂購外送

保留玩家買食物與叫外送需求。需呈現商品、數量、總價、收貨方式及訂單結果，並與實際取得物品或消費效果連動。

是否加入配送費、等待時間及 NPC 配送流程，需另行確認，不預先宣稱已實作。

### 年代適用性

Modern 可依既定方向規劃手機接單。其他年代的配送工作、聯絡及接取方式需符合時期，不直接套用現代智慧型手機 App；具體方式依年代企劃確認。

## 07｜任務、犯罪與經濟結果

保留搶車、搶劫、地下競速、黑市委託、幫派及其他既定高風險任務。

任務與犯罪可能產生：

- VE 收入或損失。
- 任務道具或其他獎勵。
- 警察反應與通緝狀態。
- 罰款、醫療與其他已規劃費用。
- 任務失敗及相關進度變化。

**規則依據：**依 `MISSION-CRIME-SYSTEM.md` 核對結果，不在經濟文件自行決定扣除全部資產、永久死亡或其他未確認懲罰。

犯罪取得物是否可持有、出售或轉換為正式資產，以及相應限制，需依載具、任務與存檔規格確認；不能預設搶到車就等於合法永久持有。

## 08｜商店與購物

玩家可在虛構商店、市場及其他既定場所購買：

- 衣服、鞋子與配件。
- 食物、飲料與食材。
- 家具、裝飾及住宅設備。
- 載具與已規劃改裝、維修服務。
- 寵物用品及配件。
- 其他已確認生活物品與任務所需內容。

購買流程需求：

選擇商品 → 查看價格與用途 → 選擇數量 → 確認總價 → 提交購買 → 確認結果 → 取得商品或服務

**檢查條件：**餘額不足、商品不適用、無法交付或交易失敗時需清楚顯示原因，不能先扣款卻未交付。背包或住宅的容量與放置限制依相關規格確認，不擅自新增限制數值。

商店商品、營業時間、庫存、退貨及出售機制的具體規則待確認，不把所有候選機制宣稱為已定案功能。

## 09｜買菜、飲食與料理

保留：

- 買菜。
- 在菜市場、黃昏市場與夜市採買。
- 買早餐、食物及飲料。
- 店內用餐或其他既定飲食互動。
- 叫外送。
- 回家簡單料理。

**流程要求：**採買需連動 VE 及物品；料理需連動可用食材、住宅設備與產出；進食需依確認後的角色狀態規則處理。

食物是否補充體力、具備其他效果或保存期限，配方、消耗及數值均待確認。不能因生活玩法存在，就自行加入強制飢餓死亡或未確認的生存懲罰。

飲酒、社交事件及酒後操作／駕駛後果依 `AUDIO-VOICE-SYSTEM.md`、角色及任務犯罪規格連動，費用統一以 VE 結算。

## 10｜日常生活循環

保留既定生活方向：

起床 → 換裝 → 餵寵物 → 吃早餐 → 出門 → 接工作／外送 → 買菜與購物 → 回家 → 休息

玩家也可探索、拍照、社交、收集、參加夜生活或執行任務，不強制每日照同一順序進行。

睡眠、休息、體力補充、換裝、物品收納、料理、寵物照護與社交聚會，需與角色及住宅系統連動。效果、消耗、時間推進方式及限制待確認。

**操作要求：**生活行為需在可操作的 3D 場景中驗證，並具備與行為相符的狀態及資料變化，不能只切換圖片或播放動畫就視為完整生活系統。

## 11｜住宅與裝潢支出

保留：

- 租金。
- 購屋。
- 家具與裝潢。
- 設備升級。
- 已規劃修繕與維修。

住宅七階段、租用與永久持有差異、家具種類、車庫、寵物空間、多人訪客及房產任務，均以 `HOUSING-PROPERTY-SYSTEM.md` 為詳細依據。

**價格方向：**依區域、房型、面積、年代、景觀、設施及地段規劃差異，可採遊戲化比例，不必完全對應現實房價。

租金週期、逾期、退租、搬家及出售等未確認項目需保持待規劃。房屋或家具交易需連動權益及存檔，不能只改餘額卻未建立持有或使用狀態。

## 12｜載具與交通支出

保留買機車、買車、收藏、改裝、維修與車庫管理的經濟連動，依 `VEHICLE-ERA-SYSTEM.md` 確認。

載具價格與服務內容需配合車型、年代及既定狀態。購買與維修需更新正式載具資料；改裝費用、零件及效果需保持一致。

燃料、充電、停車及其他交通費是否收取、如何計算，以相關系統核對與使用者確認為準，不在本文件自行新增收費制度。

換房、切換裝置或重登不應無故遺失合法持有的車輛；犯罪取得載具依第 07 章及相關文件另行處理。

## 13｜寵物與照護支出

保留初始寵物及後續取得更多寵物的既定方向，依 `PET-COMPANION-SYSTEM.md`。

生活支出可連動既定的：

- 寵物食物及用品。

- 寵物背包。

具體售價、消耗、照護效果與取得條件待確認。初始寵物不改成必須先工作賺錢才能取得，也不能因換房而重設夥伴資料。

是否支援醫療、美容等付費服務，需依寵物文件核對，不在此自行新增強制費用。

## 15｜多人合作與資產權限

保留多人工作、合作任務、社交與住宅訪客需求。

隊伍任務需區分共用進度、個人結果與各玩家獎勵。獎勵分配、任務成本及斷線後結算方式待確認，不預設平分或由隊長獨自領取。

屋主與訪客、載具持有人與隊友的權限需明確，能互動不等於能轉移或出售他人資產。

## 16｜交易、存檔與異常處理

依 `SAVE-SYNC-SYSTEM.md`，正式 VE、資產與重要進度以伺服器確認資料為準。

需求包含：

- 驗證玩家身份、權限、價格、數量及操作條件。
- 將扣款與商品／資產交付作為一致交易處理。
- 避免重複點擊、重試或重連造成重複扣款及發放。
- 記錄重要收入、支出、任務獎勵與資產異動。
- 區分進行中、成功、失敗及待確認狀態。
- 交易失敗時維持可恢復的一致狀態。
- 重登與跨裝置還原正確餘額、物品及進度。

**斷線原則：**未經伺服器確認的 VE 與資產變化不能直接成為正式結果；重連後需核對狀態，不用舊瀏覽器快取覆蓋最新資料。

本機原型可驗證流程，但 localStorage 或畫面數字不能代替正式雲端交易、存檔及同步。

- 工作及任務報酬。

餘額不足或失敗提示需說明實際原因。未讀取完成的資料不可顯示為已確認正式餘額；首頁、手機、商店、任務與其他介面的貨幣名稱保持一致。

## 18｜生活成長與經濟平衡

玩家從免費臨時借住與基本任務開始，透過任務取得收入租房，並藉由生活工作、外送及其他既定玩法累積收入，逐步改善服裝、寵物用品、載具、住宅與收藏，最終保留別墅、豪宅及其他既定長期生活目標。

成長順序是可選路線，不要求所有玩家先買機車、再買車、再買房。探索、任務、工作、犯罪與合作均應保有玩法空間。

**待平衡項目：**初始資金、收入速度、日常支出、資產價格、任務風險、解鎖條件與遊玩時間，需用實際流程測試後確認，不虛構已定案數值。

生活成本不應在未確認規則的情況下造成玩家永久失去全部進度；具體失敗與恢復方式依相關系統確認。

## 20｜核心原則

《幻都異世界》的經濟不是只有賺錢與買房。

它需連結：

**工作、外送、飲食、購物、服裝、載具、寵物、住宅、任務、犯罪、多人及不同年代的生活。**

玩家的選擇應形成自己的城市人生，所有重要 VE 與資產結果需依確認規則正確保存。

本文件是依既有方向重新整理的企劃；未確認金額與規則不視為已定案，未實作功能不宣稱完成。若與其他文件衝突，先核對並由使用者確認，不自行刪減需求。未經使用者確認，不得擅自修改、覆蓋或 Commit GitHub 正式遊戲程式。
