# 幻都異世界｜PHANTOM METROPOLIS｜Housing & Property System

## 01｜核心概念

《幻都異世界》的房屋系統代表玩家在城市中的生活成長。

玩家剛建立新角色時，不會直接擁有豪宅。

而是從最基本的居住空間開始，透過：

- 主線任務
- 支線任務
- 生活工作
- 外送
- 多人合作
- 高風險任務

累積遊戲貨幣，再逐步改善生活條件。

**貨幣名稱：**《幻都異世界》正式遊戲貨幣為「VE 幣」，遊戲介面使用「VE」作為縮寫。住宅租金、購屋、裝潢及維修等費用均使用 VE 幣結算。

**世界觀原則：**保留原本台中市中心、海線、山線、屯區等地區的住宅特色作為設計原型。遊戲內可使用虛構地區、道路、建築及房產名稱，但不能因此刪減原有探索範圍或住宅類型；建築位置與外觀不要求 1:1 複製真實地點。

---

## 02｜新手初始住所

每個新角色建立完成後，系統會提供一間：

**新手小套房**

主要功能：

- 睡眠
- 休息
- 存檔
- 換裝
- 基本物品收納
- 寵物休息
- 簡單料理
- 查看手機
- 查看任務

初始空間不追求豪華。

風格可以是：

- 老公寓套房
- 簡單出租套房
- 傳統老宅分租
- 小型雅房

依玩家選擇年代與區域調整外觀。

**首次登入銜接：**依 `GAME-FLOW.md` 規劃，玩家建立角色、完整捏角並選擇初始寵物後，取得新手住所與基本生活資金。再次登入時應讀取原有房屋狀態，不重複贈送初始房產。

### Level 4｜透天住宅

## 04｜租屋與買房

房屋取得方式分為：

### 租屋

- 初期較容易負擔
- 每期支付租金
- 無法完整改建
- 部分家具可更換

### 買房

- 一次支付較高費用
- 永久持有
- 可完整裝潢
- 可升級部分設施

**資料原則：**租用與持有應有不同的權益及存檔狀態，避免將租屋視為永久資產；逾期租金、退租、搬家及出售等細節另待規劃，不視為已完成。

---

## 05｜房屋價格

房價會依：

- 區域
- 房型
- 面積
- 年代
- 景觀
- 設施
- 地段

產生差異。

不同年代的房價可以使用遊戲化比例，不需完全對應真實房價。

**經濟連動：**租金、購屋費用、裝潢與維修支出統一使用 VE 幣，並與 `ECONOMY-LIFE-SYSTEM.md` 的貨幣及玩家收入規劃保持一致。

新手套房
→ 穩定收入
→ 買機車
→ 換公寓
→ 買車

## 15｜視覺品質

房屋與室內需符合：

- 高擬真 3D
- 真實材質
- 真實燈光
- 真實家具比例
- 可互動室內空間
- 不同年代明顯差異

### AI 視覺展示與正式 3D 住宅的區別

- **AI 寫實參考圖：**用於確認建築與室內的空間尺度、裝潢風格、光影和材質方向。
- **圖片式 HTML 展示：**可先呈現漂亮的住宅畫面與操作介面，但不代表玩家已能走入房間或自由操作家具。
- **正式 3D 住宅：**應具有可載入的室內外 3D 模型、合理碰撞與動線、家具與門窗等互動，以及角色、寵物和載具資料連動。
- **完成判定：**需檢查瀏覽器實際渲染、人物及家具比例、進出住宅、室內互動和資料保存；未經使用者確認的預覽不能取代正式遊戲版本。

## 16｜核心原則

《幻都異世界》的房屋不只是安全屋。

它代表：

**玩家從一無所有，到慢慢在幻都建立自己的生活。**

住宅需與角色、年代、地區、金錢、任務、寵物、車庫及玩家資產共同形成完整的生活系統；以上為遊戲企劃方向，不表示住宅功能已經實作完成。

**版本原則：**未經使用者確認的獨立 HTML 預覽、AI 圖片式展示或其他測試版本，不能視為正式住宅系統完成，也不得擅自覆蓋 GitHub 現有的正式遊戲程式。
