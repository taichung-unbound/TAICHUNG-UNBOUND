# 幻都異世界｜PHANTOM METROPOLIS｜Game Flow

## 01｜核心流程

玩家進入《幻都異世界》後，主要流程為：

啟動遊戲
→ 登入帳號（或依正式版本支援的方式進入）
→ 選擇角色／建立角色
→ 選擇年代
→ 選擇地區
→ 選擇遊戲模式
→ 載入角色造型
→ 載入寵物
→ 載入車輛
→ 載入玩家資產
→ 進入世界

**流程區分：**首次建立角色須完成捏角及初始寵物選擇；已建立角色的玩家應讀取既有資料，不要求每次重新建立角色或選擇初始寵物。角色與寵物建立的詳細步驟依各自系統文件規劃。

**世界觀原則：**地區以台中市中心、海線、山線、屯區等完整區域為原型，正式遊戲可使用虛構地名及地標，但不能因此刪減原本探索範圍。

---

## 02｜首次登入

第一次登入時：

1. 建立帳號
2. 驗證 Email / Google 登入
3. 建立第一個角色
4. 進入完整捏角
5. 選擇初始寵物
6. 取得新手小套房
7. 取得基本生活資金
8. 進入新手教學

**備註：**這是正式帳號及首次遊戲流程的規劃，不表示目前原型已完成 Email／Google 驗證、伺服器存檔或寵物選擇。已經有角色的玩家走第 04 章角色讀取流程。

---

## 03｜新手教學

新手教學內容：

- 角色移動
- 跑步
- 相機控制
- 地圖
- 手機
- 任務
- 商店
- 吃東西
- 換衣服
- 寵物互動
- 車輛
- 存檔

第一階段可先使用：

**現代年代的台中城市原型區域**

作為新手教學場景。正式遊戲內的地名和地標可以使用虛構名稱；新手教學的地理與生活氛圍仍保留台中特色。

---

## 04｜角色選擇

每個帳號可建立多個角色。

進入遊戲時：

登入
→ 顯示角色清單
→ 選擇角色
→ 載入角色資料

若沒有角色：

→ 建立新角色
→ 完整捏角
→ 選擇初始寵物
→ 建立並保存初始資料

**原則：**已存在角色的臉型、身材、髮型、寵物、房屋與進度應被保留；不可每次登入時重設。

---

## 05｜年代選擇

年代選擇包含：

- 1950–60s｜CITY OF TIME｜時城
- 1970s｜STREET ERA｜街代
- 1980s｜NEON YEARS｜霓虹年代
- 1990s｜STREETLINE｜街線
- 2000s｜NO LIMITS｜無限界
- Modern｜OUTLAW CITY｜狂城
- REWIND｜倒帶

部分年代可依進度解鎖。

**年代差異：**應影響街景、交通工具、NPC、服裝、髮型、商店、音樂與任務，而不只是更換選單年份。

---

## 06｜區域選擇

選擇年代後：

→ 顯示以完整台中區域為原型的世界地圖
→ 選擇可進入區域

主要區域包含：

- 市中心
- 海線
- 山線
- 屯區

以及已解鎖的：

- 大甲
- 大安
- 高美
- 梧棲
- 清水
- 豐原
- 后里
- 東勢
- 新社
- 谷關
- 大里
- 太平
- 烏日
- 霧峰

此處地名屬**開發用真實區域原型**；正式遊戲可使用另行確認的虛構名稱，並保留原型對照。完整地區、場景與其他地點，以 `MAP-TAICHUNG-SYSTEM.md` 為準，不因本章舉例較少而刪除。

---

## 07｜遊戲模式

玩家可以選擇：

### 自由探索

適合：

- 旅遊
- 開車
- 騎車
- 美食
- 拍照
- 社交
- 收集

### 故事模式

適合：

- 主線
- 支線
- 年代故事
- 地方故事
- 犯罪劇情

### 多人合作

適合：

- 組隊
- 合作任務
- 多人探索
- 犯罪任務
- 共同目標

---

## 08｜進入世界前

系統需載入：

- 角色外觀
- 年代髮型
- 年代服裝
- 寵物
- 車輛
- 房屋
- TC 幣
- 任務進度
- 收藏
- 區域狀態
- NPC 關係

**貨幣名稱備註：**「TC 幣」沿用原始企劃名稱；新版世界觀的正式貨幣名稱**尚待確認**，這次不擅自更名。

**開發狀態備註：**本章為正式遊戲預期載入項目，不代表各項伺服器資料及載入功能都已實作。

---

## 09｜世界內基本循環

玩家進入世界後可以：

探索
→ 接任務
→ 賺錢
→ 消費
→ 買衣服
→ 買車
→ 養寵物
→ 買房
→ 解鎖新區域
→ 解鎖新年代

---

## 10｜生活循環

玩家可以：

- 起床
- 換裝
- 餵寵物
- 吃早餐
- 出門
- 接工作
- 外送
- 買菜
- 逛市場
- 購物
- 回家
- 休息

---

## 11｜任務循環

接任務
→ 查看任務目標
→ 前往指定區域
→ 執行任務
→ 任務成功／失敗
→ 獲得結果
→ 儲存進度

獎勵可能包含：

- TC 幣
- 經驗
- 車輛
- 衣服
- 寵物
- 房屋
- 收藏品
- 區域聲望

**備註：**任務獎勵中的寵物，代表玩家後續可取得的寵物或擴充內容；不影響首次建立角色時可選擇初始寵物的規劃。

---

## 12｜犯罪循環

玩家可選擇進行：

- 搶車
- 搶劫
- 地下競速
- 黑市委託
- 幫派任務

犯罪後可能進入：

注意
→ 搜索
→ 追捕
→ 封鎖
→ 全面追緝

玩家成功逃脫後：

→ 犯罪紀錄更新
→ 獎勵或損失結算
→ 儲存狀態

---

## 13｜多人流程

建立隊伍
→ 邀請玩家
→ 選擇任務
→ 所有隊員確認
→ 載入區域
→ 執行合作任務
→ 結算獎勵
→ 儲存每位玩家進度

---

## 14｜死亡／重傷流程

角色嚴重受傷：

→ 任務判定
→ 醫療
→ 支付費用
→ 回到醫院／安全地點
→ 載入最近狀態

一般模式不採永久死亡。

---

## 15｜房屋流程

玩家可：

回家
→ 休息
→ 換裝
→ 使用家具
→ 照顧寵物
→ 管理收藏
→ 管理車輛
→ 邀請好友

---

## 16｜跨年代流程

REWIND 模式：

現代
→ 觸發特殊事件
→ 選擇／進入過去年代
→ 套用年代世界
→ 套用年代服裝
→ 套用年代交通
→ 執行任務
→ 返回原年代

---

## 17｜登出

玩家選擇登出時：

→ 儲存角色
→ 儲存任務
→ 儲存資產
→ 儲存位置
→ 儲存年代
→ 結束 Session
→ 返回登入頁

**備註：**此為正式存檔規劃；實際存檔與同步行為須與 `SAVE-SYNC-SYSTEM.md` 整合及驗收。

---

## 18｜重新登入

重新登入後：

→ 驗證帳號
→ 讀取角色
→ 讀取最新存檔
→ 恢復房屋
→ 恢復車輛
→ 恢復寵物
→ 恢復金錢
→ 恢復任務進度

玩家不會因登出而回到初始狀態。

---

## 19｜核心玩家成長

玩家從：

新手套房
→ 基本工作
→ 第一台機車
→ 體驗／培養初始寵物
→ 穩定收入
→ 第一台車
→ 買房
→ 解鎖更多年代
→ 解鎖更多地區
→ 建立自己的幻都生活

**初始寵物說明：**依第 02 章，玩家首次建立角色時即可選擇初始寵物；本章是「成長里程碑」，不是寵物獲得的強制時間順序。後續也可透過其他玩法取得更多寵物。

---

## 20｜核心原則

《幻都異世界》的完整體驗是：

**建立角色 → 選擇自己的年代 → 進入台中區域原型所啟發的虛構城市 → 生活、探索、合作、犯罪、成長。**

玩家原本規劃的台中市中心、海線、山線、屯區等世界範圍都須保留。遊戲中可將地區與地標虛構化，但不應刪除年代、角色捏角、寵物、載具、生活、住宅與完整世界探索的核心需求。

**版本原則：**此文件屬正式企劃規劃；未經確認的 AI 圖片展示與獨立 HTML 預覽，不視為已完成或已核准的正式遊戲功能。
