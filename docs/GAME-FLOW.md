# 台中無界｜Game Flow

## 01｜核心流程

玩家進入《台中無界》後，主要流程為：

啟動遊戲
→ 登入帳號
→ 選擇角色／建立角色
→ 選擇年代
→ 選擇台中區域
→ 選擇遊戲模式
→ 載入角色造型
→ 載入寵物
→ 載入車輛
→ 載入玩家資產
→ 進入世界

---

## 02｜首次登入

第一次登入時：

1. 建立帳號
2. 驗證 Email / Google 登入
3. 建立第一個角色
4. 進入捏角
5. 選擇初始寵物
6. 取得新手小套房
7. 取得基本生活資金
8. 進入新手教學

---

## 03｜新手教學

新手教學內容：

- 角色移動
- 跑步
- 相機控制
- 地圖
- 手機
- 任務
- 商店
- 吃東西
- 換衣服
- 寵物互動
- 車輛
- 存檔

第一階段可先使用：

**現代台中**

作為新手教學年代。

---

## 04｜角色選擇

每個帳號可建立多個角色。

進入遊戲時：

登入
→ 顯示角色清單
→ 選擇角色
→ 載入角色資料

若沒有角色：

→ 建立新角色

---

## 05｜年代選擇

年代選擇包含：

- 1950–60s｜CITY OF TIME｜時城
- 1970s｜STREET ERA｜街代
- 1980s｜NEON YEARS｜霓虹年代
- 1990s｜STREETLINE｜街線
- 2000s｜NO LIMITS｜無限界
- Modern｜OUTLAW CITY｜狂城
- REWIND｜倒帶

部分年代可依進度解鎖。

---

## 06｜區域選擇

選擇年代後：

→ 顯示台中世界地圖
→ 選擇可進入區域

區域包含：

- 市中心
- 海線
- 山線
- 屯區

以及已解鎖的：

- 大甲
- 大安
- 高美
- 梧棲
- 清水
- 豐原
- 后里
- 東勢
- 新社
- 谷關
- 大里
- 太平
- 烏日
- 霧峰

---

## 07｜遊戲模式

玩家可以選擇：

### 自由探索

適合：

- 旅遊
- 開車
- 騎車
- 美食
- 拍照
- 社交
- 收集

### 故事模式

適合：

- 主線
- 支線
- 年代故事
- 地方故事
- 犯罪劇情

### 多人合作

適合：

- 組隊
- 合作任務
- 多人探索
- 犯罪任務
- 共同目標

---

## 08｜進入世界前

系統需載入：

- 角色外觀
- 年代髮型
- 年代服裝
- 寵物
- 車輛
- 房屋
- TC 幣
- 任務進度
- 收藏
- 區域狀態
- NPC 關係

---

## 09｜世界內基本循環

玩家進入世界後可以：

探索
→ 接任務
→ 賺錢
→ 消費
→ 買衣服
→ 買車
→ 養寵物
→ 買房
→ 解鎖新區域
→ 解鎖新年代

---

## 10｜生活循環

玩家可以：

- 起床
- 換裝
- 餵寵物
- 吃早餐
- 出門
- 接工作
- 外送
- 買菜
- 逛市場
- 購物
- 回家
- 休息

---

## 11｜任務循環

接任務
→ 查看任務目標
→ 前往指定區域
→ 執行任務
→ 任務成功／失敗
→ 獲得結果
→ 儲存進度

獎勵可能包含：

- TC 幣
- 經驗
- 車輛
- 衣服
- 寵物
- 房屋
- 收藏品
- 區域聲望

---

## 12｜犯罪循環

玩家可選擇進行：

- 搶車
- 搶劫
- 地下競速
- 黑市委託
- 幫派任務

犯罪後可能進入：

注意
→ 搜索
→ 追捕
→ 封鎖
→ 全面追緝

玩家成功逃脫後：

→ 犯罪紀錄更新
→ 獎勵或損失結算
→ 儲存狀態

---

## 13｜多人流程

建立隊伍
→ 邀請玩家
→ 選擇任務
→ 所有隊員確認
→ 載入區域
→ 執行合作任務
→ 結算獎勵
→ 儲存每位玩家進度

---

## 14｜死亡／重傷流程

角色嚴重受傷：

→ 任務判定
→ 醫療
→ 支付費用
→ 回到醫院／安全地點
→ 載入最近狀態

一般模式不採永久死亡。

---

## 15｜房屋流程

玩家可：

回家
→ 休息
→ 換裝
→ 使用家具
→ 照顧寵物
→ 管理收藏
→ 管理車輛
→ 邀請好友

---

## 16｜跨年代流程

REWIND 模式：

現代
→ 觸發特殊事件
→ 選擇／進入過去年代
→ 套用年代世界
→ 套用年代服裝
→ 套用年代交通
→ 執行任務
→ 返回原年代

---

## 17｜登出

玩家選擇登出時：

→ 儲存角色
→ 儲存任務
→ 儲存資產
→ 儲存位置
→ 儲存年代
→ 結束 Session
→ 返回登入頁

---

## 18｜重新登入

重新登入後：

→ 驗證帳號
→ 讀取角色
→ 讀取最新存檔
→ 恢復房屋
→ 恢復車輛
→ 恢復寵物
→ 恢復金錢
→ 恢復任務進度

玩家不會因登出而回到初始狀態。

---

## 19｜核心玩家成長

玩家從：

新手套房
→ 基本工作
→ 第一台機車
→ 第一隻寵物
→ 穩定收入
→ 第一台車
→ 買房
→ 解鎖更多年代
→ 解鎖更多地區
→ 建立自己的台中生活

---

## 20｜核心原則

《台中無界》的完整體驗是：

**建立角色 → 選擇自己的年代 → 進入台中 → 生活、探索、合作、犯罪、成長。**
