# 台中無界｜Map & Taichung Region System

## 01｜核心概念

《台中無界》的世界不是只有台中市中心。

遊戲世界以整個台中為基礎，包含：

- 市中心
- 山線
- 海線
- 屯區
- 鄉村
- 港區
- 山區
- 海岸
- 市場
- 夜市
- 歷史街區

目標：

**讓外地玩家與國外玩家能透過遊戲認識真正的台中。**

---

## 02｜地圖架構

採用：

**完整台中世界地圖 + 區域分段載入**

玩家可以在大地圖中選擇前往不同區域。

進入區域後，再載入高細節 3D 世界。

## 21｜年代地圖差異

同一個地區在不同年代必須不同。

例如：

台中車站：

1950s
→ 早期街景

1980s
→ 舊市區與霓虹

2000s
→ 商圈與網咖

Modern
→ 現代車站與城市

---

## 22｜分區載入

玩家不會一次載入整個台中。

流程：

世界地圖
→ 選擇區域
→ 載入區域
→ 玩家探索
→ 接近下一區
→ 預載下一區

技術方向：

- Chunk Streaming
- LOD
- Occlusion Culling
- Asset Streaming

---

## 23｜快速旅行
