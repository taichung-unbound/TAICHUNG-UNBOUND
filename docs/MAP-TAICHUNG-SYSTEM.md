# 幻都異世界｜PHANTOM METROPOLIS｜Map & Taichung Region System

## 01｜核心概念

《幻都異世界》的世界不是只有台中市中心。

遊戲世界以整個台中的地區分布、城市生活與自然環境作為原型，包含：

- 市中心
- 山線
- 海線
- 屯區
- 鄉村
- 港區
- 山區
- 海岸
- 市場
- 夜市
- 歷史街區

目標：

**讓外地玩家與國外玩家透過具有台灣、台中地方特色的虛構遊戲城市，體驗不同區域的生活、文化與故事。**

世界觀原則：

- **保留真實台中各區域作為地圖規劃原型，不因虛構化而刪減原有探索範圍。**
- 正式遊戲中的地區、道路與地標名稱可採用虛構名稱；尚未討論定案者，保留原型名稱作為內部規劃標示。
- 百貨、店家、品牌、招牌及 Logo 採虛構設計。
- 城市尺度與生活氣氛可以參考真實街景，但道路、建築及地標不要求 1:1 還原，可依遊戲玩法重新編排。
- 每個遊戲內虛構名稱，應在企劃中保留對應的真實區域原型。
- 不製作可辨識的軍營、軍事基地、雷達站等敏感設施。

---

## 02｜地圖架構

採用：

**完整台中區域原型世界地圖 + 區域分段載入**

玩家可以在大地圖中選擇前往不同區域。

進入區域後，再載入高細節 3D 世界。

**重要區分：**地圖規劃以台中原型為依據；正式遊戲顯示名稱與場景細節可以虛構化，不要求完整複製真實地理位置。

## 21｜年代地圖差異

同一個區域在不同年代必須不同。

例如，以台中車站區域作為場景原型：

1950s
→ 早期街景

1980s
→ 舊市區與霓虹

2000s
→ 商圈與網咖

Modern
→ 現代車站與城市

**此處「台中車站」是開發用真實原型標籤；遊戲內車站與區域可採虛構名稱，但年代差異與地域特色必須保留。**

## 25｜核心原則

《幻都異世界》的台中區域原型不是單純的背景。

台中各地區啟發的城市與地方文化，在遊戲中應成為：

**遊戲世界、故事角色、文化內容與探索核心。**

實際遊戲地名、道路與地標可以虛構化，但**不能因此刪除原本規劃的台中市中心、海線、山線、屯區等探索內容**。
