# 幻都異世界｜PHANTOM METROPOLIS｜Mission & Crime System

## 01｜核心概念

《幻都異世界》的任務系統分成：

- 主線任務
- 支線任務
- 生活任務
- 地區任務
- 年代限定任務
- 多人合作任務
- 犯罪任務
- 隨機事件

玩家可以選擇不同生活方式，不一定要犯罪，也可以完全走：

- 外送
- 工作
- 探索
- 旅遊
- 收集
- 社交
- 租房與買房
- 買車
- 養寵物

犯罪路線也會完整存在，不因生活玩法而刪除。

**世界觀原則：**遊戲以台中市中心、海線、山線、屯區等地區的生活、道路與城市特色為設計原型，保留原先規劃的探索範圍與任務類型；正式遊戲採虛構地名、品牌、勢力與地標，不要求 1:1 還原真實地點。各地區的完整規劃以 `MAP-TAICHUNG-SYSTEM.md` 為準。

**版本定位：**本文件為遊戲企劃與後續實作驗收依據，不代表以下任務、NPC AI、追捕或多人功能已完成。未確認的金額、時限及平衡數值保留待確認。

## 03｜生活任務與新手住宅銜接

### 生活任務種類

生活任務包含：

- 外送
- 計程車
- 物流
- 搬家
- 市場工作
- 漁港工作
- 農村工作
- 商店打工
- 攝影
- 導覽
- 寵物照護
- 買菜
- 送貨
- 跑腿

生活任務主要獎勵：

- VE 幣
- 經驗值
- 區域聲望
- 商店折扣
- NPC 好感度

**貨幣原則：**《幻都異世界》的正式遊戲貨幣為「VE 幣」，遊戲介面可顯示「VE」。任務收入及生活消費與 `ECONOMY-LIFE-SYSTEM.md` 一致；實際獎勵金額與平衡數值待後續確認。

### 新手生活起點

首次建立角色、完成捏角與初始寵物選擇後，提供免費臨時借住使用資格與基本生活資金。

- 不直接贈送永久房產。
- 臨時借住不設定倒數搬離期限。
- 玩家與初始寵物可先落腳，再熟悉城市操作。
- 玩家透過任務賺取 VE 幣租房，後續累積收入買房。
- 再次登入還原既有狀態，不重複發放初始資源。

新手任務銜接：

免費臨時借住
→ 街坊跑腿
→ 取得並保存 VE 報酬
→ 在幻都安頓下來
→ 完成第一次租房
→ 自由選擇後續生活與成長路線

### 新手收入任務｜街坊跑腿

作為「在幻都安頓下來」的前置收入任務，引導新手熟悉城市操作，透過實際跑腿取得 VE 報酬。

玩家不必先買車，可步行完成。

#### 任務流程

與委託 NPC 對話
→ 查看委託內容與報酬
→ 確認接取
→ 依地圖指引前往附近商店
→ 與店員互動並取得委託物品
→ 步行前往交付地點
→ 與收件 NPC 確認交付
→ 伺服器確認完成條件
→ 完成報酬發放與進度保存
→ 銜接「在幻都安頓下來」看房與租房階段

#### 操作與年代

- 教學涵蓋移動、相機、地圖、NPC 對話、取物與交付。
- 任務目的地需清楚標示，取貨與交付階段使用不同提示。
- 委託物品需記錄取得與交付狀態，不可未取貨就完成交付。
- NPC、商店、物品及聯絡方式需符合所處年代。
- 商店與角色名稱採虛構設計。
- 初始寵物資料需保留，不因接取或完成任務而重設。

#### 報酬與租房銜接

報酬、路線長度及首次租房所需金額待遊玩測試確認。

需共同評估基本生活資金與任務收入，避免完成任務後仍無法銜接教學要求的首次租房；不在本文件設定未確認金額。

完成跑腿不等於已租到房，玩家仍需查看住宅條件、確認費用並完成租屋交易。

#### 異常處理與驗收

- 重複點擊交付、重試或重登不得重複發放報酬。
- 斷線後還原最近已確認的任務階段與物品狀態。
- 任務未完成或結算未確認時，不能顯示已領取正式報酬。
- 取消、失敗及重新接取規則待確認。
- 必須在可操作的 3D 場景中驗證步行、對話、取貨、交付與結算；示意按鈕或只增加餘額不算完成玩法。

### 新手住宅任務｜在幻都安頓下來

引導玩家使用已取得的 VE 收入，完成第一次租房，建立自己的生活空間。

#### 任務流程

接取住宅任務
→ 確認「街坊跑腿」完成狀態及已保存的 VE 收入
→ 認識可租用住宅
→ 查看租金、設備與租用條件
→ 選擇雅房／簡陋套房
→ 確認租約與費用
→ 提交租屋交易
→ 伺服器確認付款與租屋使用權
→ 保存租屋狀態及任務進度
→ 搬入第一間租屋

#### 住宅與費用原則

- 不要求新手透過犯罪才能租房。
- 租屋取得的是使用權，不是永久房產所有權。
- 租金、押金是否收取及租約週期待後續確認。
- 餘額不足或交易失敗時，需顯示實際原因。
- 租屋扣款與使用權建立應作為一致交易處理，不可只扣款卻無法入住。
- 任務報酬與租屋交易分別記錄結果，不因租屋失敗而重複發放跑腿報酬。

#### 恢復與後續成長

重試、斷線或重新登入不得重複領取報酬或重複扣款，已取得的租屋使用權與任務階段需正確保存及恢復。

玩家可透過工作、外送及其他既定玩法累積收入購屋。本任務不強制後續買車、買房或住宅升級順序。

詳細規則依：

- `ECONOMY-LIFE-SYSTEM.md`
- `GAME-FLOW.md`
- `ACCOUNT-LOGIN-SYSTEM.md`
- `SAVE-SYNC-SYSTEM.md`

## 16｜核心原則與驗收

《幻都異世界》的犯罪系統不是唯一玩法。

核心目標是讓玩家在同一個具台灣城市生活氛圍的虛構世界中自由選擇：

**生活、工作、探索、社交、犯罪、合作、冒險。**

玩家能以合法工作、購物、租房、買房、買車與養寵物建立日常生活，也可以選擇進入高風險任務並承擔相應後果。不同玩法必須共同構成完整、可持續的開放世界，而非互相取代。

### 新手任務驗收

需在實際可操作的 3D 遊戲中確認：

- 可接取「街坊跑腿」並查看目標與報酬。
- 可步行前往商店，完成對話與取物。
- 未取貨不能完成交付。
- 正確交付後，報酬與任務進度一致保存。
- 可銜接「在幻都安頓下來」，查看住宅條件與費用。
- 成功租房後取得正確使用權並可入住。
- 餘額不足或交易失敗時，不發生只扣款卻未取得使用權。
- 重試、斷線、重登及跨裝置不造成重複報酬、重複扣款或進度遺失。
- 初始寵物及既有角色資料完整保留。

### 整體完成判定

AI 參考圖片、劇情示意與獨立 HTML 預覽不等於正式任務系統完成。

必須在實際 3D 遊戲中驗證任務觸發、NPC 回應、獎勵結算、警察追捕、多人互動及存檔一致性。企劃、原型、實作與驗收狀態需明確區分，未完成項目保留並標示。

未經使用者確認，不得擅自修改、覆蓋或 Commit GitHub 正式遊戲程式。
