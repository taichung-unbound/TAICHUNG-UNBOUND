# 幻都異世界｜PHANTOM METROPOLIS｜Vehicle & Era System

## 01｜核心概念

《幻都異世界》的車輛不只是交通工具。

每個年代都必須有符合當時風格的：

- 汽車
- 機車
- 速克達
- 腳踏車
- 貨車
- 特殊交通工具

車輛要跟年代、地區、任務、生活方式一起變化。

**世界觀原則：**保留原本台中市中心、海線、山線、屯區等區域的交通生活特色作為原型；遊戲內可使用虛構地區名稱、地標、車商、品牌、招牌與 Logo。車輛及街道不必與真實品牌、地點或配置 1:1 相同，但應維持台灣城市與各年代可辨識的交通氛圍。

**開發狀態：**本文件為正式載具企劃需求，不代表每種車輛、駕駛或改裝功能已完成。先前星河大道 HTML 與 AI 視覺圖屬獨立預覽，不能當作正式遊戲已完成的載具系統。

## 03｜年代車輛

### 1950–60s

主要交通：

- 腳踏車
- 三輪車
- 早期機車
- 老式轎車
- 小型貨車
- 農用車

- 車輛數量較少
- 道路較單純
- 車速較慢
- 老式車燈與引擎聲

### 1970s

主要交通：

- 經典轎車
- 老式機車
- 小貨車
- 計程車
- 腳踏車

特色：

- 車輛開始增加
- 更多商業運輸
- 老街與市場周邊交通密集

### 1980s

主要交通：

- 經典房車
- 經典機車
- 速克達
- 計程車
- 貨車
- 夜生活車輛

特色：

- 霓虹街區
- 夜間車流
- 地下競速
- 幫派任務
- 改裝雛形

### 1990s

主要交通：

- 房車
- 改裝車
- 速克達
- 街頭機車
- 小貨車
- 計程車

特色：

- 改裝文化增加
- 機車數量高
- 街頭競速
- 電玩／網咖街區交通

### 2000s

主要交通：

- 轎車
- 跑車
- 改裝車
- 速克達
- 機車
- 廂型車
- 計程車

特色：

- Y2K 車輛風格
- 街頭改裝

- 早期外送／跑腿型交通

### Modern

主要交通：

- 現代轎車
- SUV
- 跑車
- 電動車
- 速克達
- 重機
- 外送機車
- 計程車
- 共享交通

- GPS
- 智慧導航
- 外送
- 車牌辨識

**年代一致性：**車輛型式、道路密度、交通設備、角色衣著、NPC 騎乘方式與聲音須共同呈現年代差異，不是只替換車色或年代標籤。上述項目均屬規劃目標。

- 購買
- 任務獎勵
- 特殊活動
- 收藏解鎖
- 二手車市場
- 地區限定

- 真實輪胎
- 真實車燈
- 真實反射
- 真實內裝
- 真實損壞效果

### AI 視覺展示與正式 3D 載具的區別

- **AI 寫實參考圖：**用於確認車型、騎士比例、台灣道路氛圍、光影與交通密度。
- **圖片式 HTML 展示：**可先呈現接近參考圖的畫面，但不等於車輛已能實際行駛或從不同方向觀看。
- **正式 3D 載具：**需有可載入的 3D 模型、適當材質、車輛控制、騎乘動畫及互動；不能以遠景貼圖或簡單積木模型冒充最終品質。
- **完成判定：**必須檢查瀏覽器實際渲染、車人比例、駕駛視角、上車下車及操控表現，並由使用者確認是否符合預期。未經確認的獨立預覽不得覆蓋正式版本。

## 20｜核心原則

《幻都異世界》的車輛要讓玩家一眼看出：

**這是哪個年代、哪個地區、哪種生活方式。**

保留原本台中各區域原型與六個年代的交通特徵，並以虛構地區、地標與品牌建構遊戲世界。車輛不只是展示品，而應逐步成為能駕駛、工作、探索、購買、改裝、維修及與任務連動的遊戲系統。

**版本原則：**本文件為企劃需求；尚未完成的功能不得標示為已實作。未經使用者確認的星河大道 3D 預覽、AI 圖片與 HTML 視覺展示，不視為正式車輛系統完成，也不取代 GitHub 現有正式遊戲程式。
